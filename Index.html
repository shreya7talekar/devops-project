Welcome to Our DevOps Project

Welcome to our collaborative DevOps project. This website demonstrates how a development team can work together using Git, GitHub, branches, commits, and pull requests.

Each team member contributes to the project through an independent development branch.

What We Demonstrate

Git

Git is used to track changes and maintain different versions of our project.

GitHub

GitHub allows our team to store the project online and collaborate with each other.

Pull Requests

Team members submit their changes through pull requests before they are merged.

Our Development Approach

Our team follows a collaborative development workflow. Developers create separate branches, make changes, commit their work, and create pull requests. The repository owner reviews the changes and merges approved contributions into the main branch.
